# Unity3d-first-person-mobile-controller
unity first person mobile controller

## Kıvılcım Adası (mobil survival prototipi)

`survival-game/` klasöründe tarayıcıda çalışan, telefona uyumlu 2.5D tepeden bakış bir hayatta kalma oyunu var. Kurulum gerekmez.

- `survival-game/index.html`: tek başına açılan sürüm (telefonda tarayıcıyla aç).
- `survival-game/game.html`: aynı oyunun Claude Artifact sürümü (sayfa iskeleti yayınlanırken eklenir).

**Nasıl oynanır**

- Ekranın sol yarısına dokunup sürükle: yürü.
- Turuncu tuş: ağaç kes, taş kır, meyve topla, sandık aç, gölgeciklere vur. Basılı tutunca tekrarlar.
- Üret: Kamp Ateşi, Balta, Mızrak, Mantar Çorbası, Fener, Çadır. Menü açıkken oyun durur.
- Ye: en doyurucu yiyeceği yer.
- Gece gölgecikler çıkar, ışıktan korkarlar. Ateşin yanında kal ve odun atarak besle.
- Harabelerdeki sandıklarda ve araba enkazlarında 5 telsiz parçası bul, kamptaki telsize tak. Ertesi sabah kurtarma teknesi gelir.

Klavye: WASD/oklar yürü, Boşluk/E eylem, F ye, C üret, Esc mola. İlerleme her birkaç saniyede tarayıcıya kaydedilir.
